    cd backend/api
    ./mvnw spring-boot:run

    cd frontend/backoffice
    npm run dev

  Terminal 3 - Site public :
    cd frontend/stemadeleine
    npm run dev

  Ensuite :
    → Ouvrir http://localhost:3001/settings
    → Section "Favicon du site"
    → Uploader une image
    → ✨ Magie ! Le favicon change !

  AVANT (❌) :

    Settings → Upload favicon → Sauvegarde dans la DB
                                       ↓
                            MAIS le site ne le voit pas
                            Il utilise toujours favicon.ico statique


  APRÈS (✅) :

    Settings → Upload favicon → Sauvegarde dans la DB
                                       ↓
                          API /api/public/organization/settings
                                       ↓
                          DynamicFavicon (composant React)
                                       ↓
                          Remplace <link rel="icon"> dans le DOM
                                       ↓
                          Pointe vers /api/public/media/{id}
                                       ↓
                          ✨ Favicon affiché sur tous les sites ! ✨
