╔═══════════════════════════════════════════════════════════╗
║  ✅ ÉTAPE 1 : VALIDATION                                   ║
╚═══════════════════════════════════════════════════════════╝

    chmod +x validate-favicon-setup.sh
    ./validate-favicon-setup.sh

    → Si tout est ✓ vert, passez à l'étape 2
    → Si des ✗ rouges apparaissent, corrigez-les d'abord


╔═══════════════════════════════════════════════════════════╗
║  🚀 ÉTAPE 2 : DÉMARRAGE                                    ║
╚═══════════════════════════════════════════════════════════╝

    Terminal 1 - Backend :
    ┌─────────────────────────────────────────────────────┐
    │ cd backend/api                                      │
    │ ./mvnw spring-boot:run                              │
    └─────────────────────────────────────────────────────┘

    Terminal 2 - Backoffice :
    ┌─────────────────────────────────────────────────────┐
    │ cd frontend/backoffice                              │
    │ npm run dev                                         │
    └─────────────────────────────────────────────────────┘

    Terminal 3 - Site public :
    ┌─────────────────────────────────────────────────────┐
    │ cd frontend/stemadeleine                            │
    │ npm run dev                                         │
    └─────────────────────────────────────────────────────┘


╔═══════════════════════════════════════════════════════════╗
║  🎨 ÉTAPE 3 : UPLOAD DU FAVICON                            ║
╚═══════════════════════════════════════════════════════════╝

    1. Ouvrir navigateur → http://localhost:3001/settings

    2. Scroller vers le bas → Section "Favicon du site"

    3. Cliquer sur "Ajouter un média"

    4. Choisir une image (ICO, PNG, SVG)
       Tailles recommandées : 32×32 ou 64×64

    5. Cliquer sur "Upload"

    6. ✨ MAGIE ! Le favicon change dans l'onglet !


╔═══════════════════════════════════════════════════════════╗
║  ✨ ÉTAPE 4 : VÉRIFICATION                                 ║
╚═══════════════════════════════════════════════════════════╝

    1. Regarder l'onglet du backoffice
       → Le favicon devrait être votre nouvelle image ! ✓

    2. Ouvrir un nouvel onglet → http://localhost:3000
       → Le même favicon devrait apparaître ! ✓

    3. Si le favicon n'a pas changé :
       → Appuyez sur Ctrl+Shift+R (Cmd+Shift+R sur Mac)


╔═══════════════════════════════════════════════════════════╗
║  🔧 DÉPANNAGE RAPIDE                                       ║
╚═══════════════════════════════════════════════════════════╝

    ❌ Le favicon ne change pas ?
    └→ Ctrl+Shift+R (force le rafraîchissement)

    ❌ Erreur dans la console ?
    └→ F12 → Console → Lire les messages d'erreur

    ❌ Backend non accessible ?
    └→ Vérifier que le backend tourne sur le port 8080

    ❌ Toujours bloqué ?
    └→ ./test-favicon.sh (diagnostic complet)

    Pour voir le changement EN DIRECT :

    1. Ouvrez 2 onglets côte à côte :
       ├─ Gauche : http://localhost:3001/settings
       └─ Droite : http://localhost:3000

    2. Uploadez un nouveau favicon dans l'onglet de gauche

    4. ✨ Le favicon change instantanément ! ✨
